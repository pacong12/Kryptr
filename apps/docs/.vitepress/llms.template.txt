# Kryptr Docs

> Kryptr is a security-gated finance layer for autonomous agents on Base and
> Robinhood Chain. Agents propose structured intents; a security gate
> (origin allowlists, spend caps, human-in-the-loop approval) decides before
> anything else happens. Phase 1: signing is dry-run only — nothing is
> broadcast on-chain yet.

This is the official Kryptr user documentation. Every page carries a status:
**live** (available today), **preview** (built, not fully enabled),
**planned** (designed and contract-frozen, not available). Security claims
are traceable to the Kryptr research corpus; verification statements never
go beyond "passed the verification battery — this is not a warranty".

## Features

- [Balances & history]({{DOCS_URL}}/features/balances-and-history.html):
  read-only balances with honest zeros; every action leaves a recorded gate
  decision.
- [Swaps & quotes]({{DOCS_URL}}/features/swaps-and-quotes.html):
  quote → bound intent → gate → unsigned preview; nothing executed yet.
- [Orders & kill switch]({{DOCS_URL}}/features/orders-and-kill-switch.html):
  limit and DCA orders, frozen lifecycle, oracle triggers, three-mode kill
  switch (off / pause_new / cancel_active). Status: preview.
- [Launchpad consent]({{DOCS_URL}}/features/launchpad-consent.html):
  token launches with consent-frozen fees (reference 175 bps), on-chain bond,
  T21 verification. Status: planned — no factory deployed, launchpad dark.
